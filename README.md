# AntAF · 蚂蚁阿福体重秤大屏

把蚂蚁阿福体重秤（AFU-WL-TZ-A1）接入本地电脑，实时称重、自动估算 18 项身体成分，并在 iPad / 平板上以「体重居中、指标环绕」的大屏仪表盘展示。界面按远距离阅读重新设计：大字号、大单位、大触控区，并为 iPad 横屏 / 竖屏、手机分别做了自适应。

支持多成员档案：**先测量、再把记录归属到人**，体成分按每位成员的身高、年龄与性别独立计算。

> 秤本身只回传重量与阻抗，且只有一个用户槽位；历史记录与「这次是谁称的」全部由本项目在本地维护。

## 功能

- **实时称重**：BLE 直连私有服务，重量随踩秤即时刷新，稳定后自动建档（单位 kg，精确到 0.01 kg）；
- **阻抗测量**：连接后自动下发时间 + 用户资料包，使能阻抗测量，收到阻抗后按 BIA 公式本地估算体成分；
- **大屏仪表盘**：中心是大号体重读数与单位，BMI、体脂率、肌肉量、水分率四张卡片环绕；右侧抽屉展开全部 18 项指标、7/30 天趋势与测量记录；
- **适老大字号**：体重最高 168px、卡片数值最高 68px、单位与等级标签同步放大；iPad / 手机等小屏会自动放大圆球与卡片，而不是缩小可读性；
- **多成员档案**：姓名、身高、年龄、性别、标识色；页面底部可直接新增成员，成员芯片右侧的铅笔可修改姓名与资料，垃圾桶可删除；资料变更后自动重算该成员名下全部记录；
- **先测量后归属**：每次稳定读数先生成一条「待分配」记录，再在记录行里选择成员完成归属，归属关系可随时修改；
- **自动归属建议**：出现待归属记录时，底部成员栏会按各成员最近三次体重推荐最接近的人，点一下「归属给 ×××」即可完成，无需每次手动选人；如果这次读数不想要，点旁边的「放弃本次」并确认即可删除；
- **记录与趋势**：每条记录带年月日时分秒；抽屉内可按 7 天 / 30 天查看体重、体脂率迷你趋势图，并显示「较上次 ±x.xx」；每条记录都有「归属」和「删除」按钮，删除前二次确认；
- **删除保护**：成员名下还有记录时，垃圾桶按钮半透明禁用，点击只会抖动并提示先转移归属，不会打开删除确认；
- **深浅主题**：顶部一键切换，深色模式使用高对比文字与纯黑背景，局域网大屏夜间也清晰；
- **iPad 自适应**：横屏四角环绕、竖屏上下两排、手机纵向堆叠；抽屉、弹层、提示条均带安全区适配；
- **本地持久化**：成员与记录保存在 SQLite，服务重启不丢失；同一称重的重复稳定帧自动合并，阻抗帧补全到同一条记录。

## 环境要求

- Windows 10 / 11，电脑具备可用蓝牙；
- Python 3.10+（本机也验证过 Python 3.13）；
- Chrome / Edge 等现代浏览器（局域网内的平板 / 手机也可访问）。

## 快速开始

```powershell
# 首次运行
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动服务
.\.venv\Scripts\python.exe server.py
```

如果电脑上已有可用的 Python 3.10+，也可以直接：

```powershell
python server.py
```

启动后终端会打印访问地址：

```
访问地址：
  http://127.0.0.1:8765
  http://192.168.x.x:8765
```

本机打开 `http://127.0.0.1:8765`；iPad / 平板在同一 Wi-Fi 下打开 `192.168.x.x` 地址（Windows 防火墙弹窗请勾选「专用网络」）。

## 页面与操作

### 仪表盘

- **中心圆**：显示当前体重或选中的历史记录，单位单独放大显示；下方标注「实时测量 / 上次测量 · 今天 14:23:05」；
- **四张环绕卡片**：BMI、体脂率、肌肉量、水分率，带等级标签（绿 = 标准 / 优秀，黄 = 偏低 / 偏高，红 = 过高）；
- **底部成员栏**：左侧成员芯片显示最近一次体重与精确到秒的时间；出现待归属记录时，最前面会出现「归属给 ×××」的一键确认芯片与「放弃本次」删除芯片；点击成员芯片可筛选该成员的记录，铅笔按钮编辑姓名 / 身高 / 年龄 / 性别，右侧垃圾桶删除成员；「新增成员」按钮始终可见；
- **右侧抽屉**：点击屏幕右缘的箭头展开，显示 18 项身体成分、7/30 天体重与体脂率趋势以及测量记录；抽屉打开后，收起按钮位于抽屉右上角；
- **顶部栏**：年月日 + 时分秒时钟、实时通道延迟、秤连接状态与深浅主题切换。

### iPad / 手机布局

| 屏幕 | 布局 |
| --- | --- |
| iPad 横屏 / 桌面 | 体重圆居中，四张卡片分布在四个角，卡片与圆球之间保持安全间距 |
| iPad 竖屏 | BMI / 体脂率在圆球上方一排，肌肉量 / 水分率在下方一排，卡片加宽 |
| 手机 | 体重圆在最上，四张卡片纵向排列，页面可滚动；底部成员栏固定 |

### 成员与记录

1. **先测量**：任意成员光脚上秤，服务在稳定读数出现时立即建档（同一次称重的重复稳定帧自动合并为一条记录，后续到达的阻抗帧会补全到同一条），记录时间精确到秒；
2. **一键归属或放弃**：最后一条记录尚未归属时，底部成员栏会按各成员最近三次体重的均值推荐最接近的人，并显示参考体重与差值；点击「归属给 ×××」即完成归属；若这次读数不想要，点「放弃本次」确认后删除，记录不会计入趋势；
3. **手动归属**：也可在右侧抽屉的「测量记录」里点击「归属」，选择其他成员或取消归属；未归属记录在归属弹窗里同样可以「放弃这条记录」；
4. **按人重算**：归属后服务端用**该成员**的身高 / 年龄 / 性别与本次阻抗重新执行 BIA，体成分因此与「谁称的」一致；修改成员资料后，其名下所有记录的体成分会自动重算；
5. **编辑成员**：点击成员芯片右侧的铅笔按钮，可修改姓名、身高、年龄与性别；改名后成员芯片、历史记录与趋势标题会立即使用新名字；
6. **趋势对比**：抽屉的记录区顶部提供 7 天 / 30 天切换，按天去重后绘制体重与体脂率迷你曲线，并显示最近两次的差值；默认展示最近一次归属成员，选中记录或筛选成员后跟随切换；
7. **删除记录**：记录行的「删除」按钮会弹出确认框，确认后立即删除并同步到所有打开的页面；
8. **删除成员**：成员芯片右侧的垃圾桶按钮；若该成员名下还有记录，按钮会以禁用态显示，点击仅抖动并提示先转移归属，不会弹出删除确认；
9. **同步秤资料**：最近一次被归属的成员资料会作为下发给秤的用户资料包（只用于使能阻抗测量，体成分以本地重算为准）。

对应的 WebSocket 指令：`add_user` / `update_user` / `delete_user` / `assign_record`（`user_id` 传 `null` 取消归属）/ `delete_record`；变更后会向所有页面推送 `weight_state`，其中每位成员附带 `record_count`，并附带按最近体重计算的 `suggestion`（没有待归属记录时为 `null`）。

## 协议（实测）

秤使用私有服务 `0xFFB0`：写入特征 `FFB1`、通知特征 `FFB2`，**无需配对、无需认证**。服务启动后会自动连接扫描到的 `AFU*` 设备。

通知帧共 20 字节，包头 `0xAC`，`data[1]` 为设备型号（本机 `0x29`），包类型在 `data[18]`，序号在 `data[19]`：

```
体重包 0xD5    ac 29 | <32 位体重编码> | … | 29 d5 | 序号
阻抗包 0xD6    ac 29 02 | <通道数> | <2 字节×通道数> | <mode> | <32 位体重编码> | … | 29 d6 | 序号
资料应答 0xD8  ac 29 01 | … | … | 29 d8 | 序号
```

体重编码是 32 位大端数：低 18 位为克数，`bit18-20` 为刻度精度（division），**`bit31` 为稳定标志**。换算（1 个计数 = 1 克）：

```
kg = (编码 >> 0) & 0x3FFFF  →  克数，再按 division 档位取整为显示值
```

该关系用三个实测点验证过，误差为 0：`6889994 → 74.250 kg`、`6890044 → 74.300 kg`、`6829744 → 14.000 kg`。称重过程中帧间隔约 120 ms，可做实时滚动；稳定后连续推送结果帧。

阻抗包的 `data[2]` 是通道数，真正的阻抗值在 `data[4:4+2*count]`（每通道 2 字节大端），本机 `count=2`，实测光脚 `583/536 Ω`、`637/580 Ω`，穿袜子时 `699/642 Ω`（接触电阻更大）。

### 体成分资料包（0xD0）

秤默认只称体重，**不会**主动测阻抗。要拿到体成分，必须在连接后向 `FFB1` 下发「时间 + 用户资料」包（包类型 `0xD0`），使能功能位 `0x03`：

```
AC | 型号 | 时间4B(大端) | 时区(15min单位) | 单位0 | 用户号1 | 身高
   | 档案体重00 | 年龄 | 性别(1男/2女) | 目标体重00 | 功能位03 | 00 | D0 | 校验和(2..18求和)
```

服务连上秤后立即下发资料包，并每 15 秒重发一次；秤收到后回 `0xD8` 应答，随后称重结束才会发出 `0xD6` 阻抗包。收到阻抗后由 [body_composition.py](weight/body_composition.py) 按体重、阻抗、身高、年龄、性别本地计算。

默认资料为 **身高 173 cm、年龄 25 岁、男性**（可用 `--scale-height/--scale-age/--scale-sex` 修改；首次创建成员后也可在页面中新增 / 删除成员维护资料）。

## 指标与分级

页面共展示 18 项指标（BMI + 17 项身体成分）。每张指标卡为两行：第一行是指标名与等级标签，第二行是大号数值；除基础代谢（kcal）与内脏脂肪等级（级）取整外，**所有测量与估算数值统一保留两位小数**。等级标签使用绿 = 标准 / 优秀，黄 = 偏低 / 不足，红 = 偏高 / 高 / 过高：

| 指标 | 单位 | 等级 | 计算 / 分级依据 |
| --- | --- | --- | --- |
| BMI | — | 无 | 体重 / 身高² |
| 内脏脂肪等级 | 级 | 标准 / 高 | `BMI×0.3 − 年龄×0.05 + 0.4`（限 1–50）；1–9 标准，≥10 高 |
| 体脂率 | % | 偏低 / 标准 / 偏高 / 过高 | BIA 公式；按性别与年龄分段阈值 |
| 脂肪量 | kg | 同体脂率 | 体重 × 体脂率 |
| 皮下脂肪率 | % | 偏低 / 标准 / 偏高 | 体脂率 × 0.71，阈值按同比例缩放 |
| 皮下脂肪量 | kg | 无 | 体重 × 皮下脂肪率 |
| 体水分率 | % | 偏低 / 标准 / 偏高 | `(100−体脂率)×0.7` 修正；男 50–65%，女 45–60% 为标准 |
| 体水分量 | kg | 同体水分率 | 体重 × 体水分率 |
| 蛋白质含量 | kg | 不足 / 标准 / 优秀 | 去脂体重 × 0.238；占比 16–20% 标准，>20% 优秀 |
| 蛋白质占比 | % | 无 | 蛋白质含量 / 体重 |
| 骨量 | kg | 偏低 / 标准 / 偏高 | BIA 公式；按性别与体重分档标准区间 |
| 骨量占比 | % | 无 | 骨量 / 体重 |
| 肌肉量 | kg | 偏低 / 标准 / 优秀 | 体重 − 脂肪量 − 0.85×骨量；按性别与身高分档 |
| 肌肉率 | % | 同肌肉量 | 肌肉量 / 体重 |
| 骨骼肌量 | kg | 偏低 / 标准 / 偏高 | 肌肉量 × 0.558；参考 Janssen MRI 男 33 kg / 女 21 kg，±10% 为标准 |
| 骨骼肌率 | % | 同骨骼肌量 | 骨骼肌量 / 体重 |
| 基础代谢 | kcal | 无 | Mifflin-St Jeor（1990） |
| 去脂体重 | kg | 无 | 体重 − 脂肪量 |

> **标准说明**：真正有权威依据的只有 Mifflin-St Jeor 基础代谢公式、AWGS 2019 肌少症 ASM 口径与 WHO 的 BMI 分界；体脂率分龄阈值、内脏脂肪公式、骨量 / 肌肉量分档、水分 / 蛋白质 / 皮下脂肪区间均来自厂商 SDK 或社区实现（ha-miscale2、icomon_scale、ant-afu-welland-scale、Omron / Tanita 说明书），**属于经验参考值，不能作为医学诊断依据**，不同品牌之间不可直接比较。
>
> 体成分是**基于 BIA 公式的估算值**，不是医疗级测量；阻抗受脚底湿度、站姿、袜子影响较大，请固定条件、光脚测量。

## 使用

1. **踩一下秤**唤醒它（休眠时不会广播，服务就搜不到）；
2. **光脚**站上去保持不动约 2 秒，中心圆先显示实时重量，稳定后停住；
3. 稳定后稍等 1–3 秒，秤补发阻抗包，记录里会带上阻抗；
4. 底部出现「归属给 ×××」时，点一下即可按推荐成员完成归属；也可以点击记录行的「归属」手动选择，中心圆与右侧抽屉随即按该成员资料展示体成分；
5. 穿袜子只会得到更大的阻抗（甚至测不到），此时该记录仅有体重，归属后也不显示体成分；
6. 打开右侧抽屉可查看全部 18 项指标；在「测量记录」上方切换 7 天 / 30 天查看体重与体脂率趋势，下方可归属或删除历史记录。

## 故障排查

| 现象 | 可能原因与处理 |
| --- | --- |
| 页面一直显示 `--` | 秤处于休眠；踩一下唤醒。仍无反应时确认秤在附近、设备名以 `AFU` 开头（可用 `--scale-match` 指定其他前缀） |
| 启动提示「蓝牙扫描启动失败」 | 适配器被禁用、驱动异常，或系统隐私设置禁止应用访问蓝牙 |
| 局域网设备打不开 | Windows 防火墙未放行、平板与电脑不在同一网段、路由器开启了 AP 隔离 |
| 体重读数偏小 | 单脚压秤只读到部分重量，需双脚站稳静止约 2 秒；秤应放在硬质平整地面 |
| 阻抗一直为 `--` 或为 `0 Ω` | 未光脚 / 穿了袜子 / 脚底太干；擦干脚底光脚站稳，等秤补发阻抗包 |
| 有体重但没有体成分 | 阻抗未测到（同上），或记录尚未归属成员；先在记录行选择归属，服务会按该成员资料重算 |
| 成员无法删除 | 该成员名下还有记录，垃圾桶按钮会显示为禁用态并抖动提示；先把记录归属到其他成员或删除记录 |
| 归属推荐不准 | 推荐只依据各成员最近三次体重；成员刚建档或体重变化较大时，请手动在记录行选择归属 |
| 打开页面仍是旧样式 | 浏览器缓存了旧脚本。确认 `index.html` 中 `bundle.js?v=` 已更新，或强制刷新（Ctrl+F5） |

## 开发与构建

前端按 ES 模块拆分，浏览器实际加载的是拼接后的 `bundle.js`（普通脚本，避免旧浏览器 / 局域网环境的模块加载问题）。修改 `weight/web/js/` 下的模块后重新构建：

```powershell
node weight/web/js/bundler.js
```

构建完成后，把 `weight/web/index.html` 中 `bundle.js?v=` 的版本号改成一个新值，避免浏览器继续使用缓存。CSS / HTML 改动也建议强制刷新验证。

项目当前没有自动化测试；改动后请至少在 Chrome 的 iPad 横屏（1180×820）、iPad 竖屏（820×1180）、手机（390×844）与窄屏（320×720）尺寸下检查：体重与卡片不重叠、顶部年月日时分秒不截断、抽屉可开合、7/30 天趋势与较上次差值正常、一键归属与成员删除拦截可操作、深浅主题文字清晰。
